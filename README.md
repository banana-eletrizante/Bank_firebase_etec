# Bank Firebase ETEC

Simulação de banco em Ionic + Angular + Firebase (projeto de curso).

```bash
npm install
# copie src/environments/environment.example.ts para environment.ts
# e preencha as chaves do Firebase Console
ionic serve
```

Configuração do Firebase: `src/environments/environment.ts` (não commite chaves reais).
No Console, restrinja a API key por app/domínio. A key antiga que estava no código deve ser rotacionada no projeto `bank-db-ab48a`.
